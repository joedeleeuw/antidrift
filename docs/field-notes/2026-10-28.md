## Shape sample: a framework as derive + enforce on tsrs

Prototype: `apps/shape-sample` plus `antidrift-linter derive <package-root>` (`crates/antidrift-linter/src/derive/`). Roles come from directories, not directives: `methods/` (one `export async function` per file, file name is the wire name, `async` is the network hop), `pubs/` (`async function*`, the yield type is the wire patch), `routes/` (verb exports returning `Promise<Response>`), `shared/` (sync only, it runs on the client as the simulation), `server/` (reachable only from server roles), `client/`. Injected parameters are recognized by type name (`Session`, `AbortSignal`), must come last, and are dropped from client stubs.

Derive reads parameter and return types from the tsrs checker and writes `src/generated/`: `wire.ts` (type aliases via `Parameters<typeof import(...)>`, structural decoders), `client.ts` (stubs), `server.ts` (dispatch table over dynamic imports), `manifest.json`, `derive-report.json`. tsc checks every generated decoder against the owning signature, so a wrong derivation fails typecheck. `NoInfer` on the decoder helper callbacks is what carries contextual types into nested decoders; without it the first union arm wins inference and the other arms error.

Measured on the sample: derive flags exactly the six planted violations (sync method, misnamed export, function-typed parameter, async shared, client importing server, sync route) and emits 2 methods, 1 publication, 1 route; `tsc --noEmit` exits 0; the smoke (`tsx apps/shape-sample/smoke/run.ts`: in-process `Request`/`Response` handler, NDJSON publication stream) passes 7/7 (Date round-trip, boundary rejection naming `args[0].title`, ownership through the injected session, live patches with abort on client stop, optimistic patch then reconciliation, route GET and 404). Rust gates (`cargo build`, `cargo clippy -D warnings`, `antidrift-linter rust`) pass after splitting `wire_shape.rs` into the type walker and `contracts.rs` for the 500-line budget.

The existing rules on the same package: 16 findings, none of them the framework violations. `no-wrapping-functions` and `no-pass-through-parameters` fire on generated stubs and decoders (those rules do not skip `generated/`), `require-fetch-timeout` on the runtime transport, and `no-structural-type-fork` names `Todo` as a restatement of the generated `AddTodoResult` (owner chosen backwards). `require-authz-check` stays silent on `addTodo`, which has no authz call, because it keys on `params` member access; `boundaries.yaml` `serverBoundaryGlobs` is read by no Rust rule, so the registry's route globs are dead configuration today.

Open: decoders reject index signatures, tuples, classes and bigint; route params are untyped (`Record<string, string>`); generated code is not excluded from the hop and pass-through rules; the sample is not installed in the pnpm workspace (it runs on the root `tsc` and `tsx`). Nothing committed.
