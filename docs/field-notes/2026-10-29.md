# Field Notes — 2026-10-29

## 1. CLI, `--help`, and Cargo Workspace Discovery Remediation

- **Positional `--help` and `--version`:** Previously, `main.rs` only inspected `raw_vec.first()` for `--help` / `-h` and `--version` / `-V`. Invoking `antidrift-linter <path> --help` failed with `unknown flag: --help` (`exit 2`), and the top-level usage string omitted `--batch-json`, `--suppress-rule`, `--prune-suppressions`, `--suppressions-location`, and `--report-unused-disable-directives`. Fixed `main.rs` to honor `--help` / `-h` and `--version` / `-V` in any argument position (outside `headless`) and print the complete flag surface.
- **Unified `--json` / `--format` across TS and `rust`:** Added `--json` as an alias for `--format json` in `cli.rs` and added `--format human|stylish|json` to `rust/mod.rs` so both modes accept identical output flags.
- **`PolicyRegistries` ancestor resolution:** `PolicyRegistries::load_from_repo` previously checked only `cwd/policy/registries`. Updated `registries.rs` and `runner.rs` to walk ancestors from the target path (falling back to `cwd`) so linting a subdirectory or external checkout resolves its enclosing `policy/registries` directory.
- **Recursive Cargo workspace discovery & `rust/no-orphan-module` path semantics:**
  - `discover_crate_dirs` previously checked only `root/Cargo.toml` (when `root/src` existed) or one directory level under `root/crates`, returning `0 files checked` on nested Cargo workspaces (`grok-build/crates/codegen/*`, `claurst/src-rust/crates/*`). Replaced with recursive crate discovery (`collect_crate_dirs_recursive`).
  - `check_orphan_modules` previously treated only `src/lib.rs` and `src/main.rs` as roots and resolved `#[path = "..."]` relative to `parent/<stem>` instead of the declaring file's directory (`file_dir`), causing false positives on `src/bin/*.rs` targets and `#[path = "sibling_tests.rs"] mod tests`. Added `src/bin/**` target roots, lexical path normalization (`..` / `.`), and dual `file_dir` / `search_dir` resolution for `#[path = "..."]`.

## 2. `gpt-6-astra` (`xhigh`) Audit Precision Fixes (`52410ed` & `rust/*`)

- **CF-1 (`no_identity_schema_transform.rs`):** Restricted `returned_object_literal` call-argument unwrapping to single-argument calls so multi-argument helpers are never misclassified as identity transforms.
- **CF-2 (`schema_context.rs`):** Added support for Valibot/Effect pipe transforms (`v.pipe(schema, v.transform(fn))` and `pipe(schema, transform(fn))`), extracting the input schema from the first `pipe` argument.
- **CF-3 (`sum_erasure.rs`):** Excluded object literals with `SpreadAssignment` (`...source`) or an existing discriminant property (`status`, `kind`, `_tag`, `state`, `phase`) from `find_sum_to_product_erasure`.
- **CF-4 (`json_parse.rs`):** Replaced recursive `contains_json_stringify` on variable initializers with `is_direct_json_stringify_expr` so `fetch(url, { body: JSON.stringify(req) })` is not misclassified as a `JSON.stringify` roundtrip source.
- **CF-5 & CF-6 (`shadow_state_mirror.rs`):**
  - Excluded `get*` method references (`useState(controller.getSnapshot)`) and required `is_effect_only_mirror` calls to occur directly inside the effect body with an argument matching the initial prop/hook source (`same_mirror_source`), eliminating all 6 false positives on `grok-bot-reconstructed`.
  - Required `classify_object_literal_writes` to match at least two lifecycle properties including a boolean literal (`TrueConst` / `FalseConst`), eliminating the discriminated-union false positive on `setPublishTargets({ kind: "unavailable", reason })`.
- **CF-7 (`await_waterfall.rs`):** Allowed self-joins (`outer_receiver == inner_receiver`) and JSX-returning outer `.map` callbacks in `relational_key_join_calls`, catching $O(N^2)$ reply/parent lookups in `grok-bot-reconstructed` (`channels/view.tsx:46`, `transcript.tsx:700`).
- **CF-10 (`rust/boundary_decode.rs`):** Fixed `expect("msg")` 1-argument peeling, `Expr::Paren` unwrapping, serde crate path verification in `is_serde_call`, and diverging closure exemption (`.unwrap_or_else(|e| panic!(...))`) in `rust/no-decode-to-option`.
- **CF-11 (`constant_return_field.rs`):** Restricted `is_delegating_call_return` to calls targeting another function in the same contract group (`entries.len() > 1`), eliminating the `pokeHostUpgrade` (`return await deadline.run(...)`) false positive.
- **R1, R3, R4, R8 (`rust/{rules,smells,struct_shapes}.rs`):** Excluded `Serialize` structs from `rust/no-constant-return-field`, exempted RAII guard/permit/marker fields (`_guard`, `_permit`, `PhantomData`) from `rust/no-let-underscore-suppression`, exempted generic `Serializer`/`Deserializer` adapters from `rust/no-wrapping-functions`, fixed `#[cfg(not(test))]` in `rust/no-inline-tests`, and generalized `rust/no-untyped-config-probe` remediation wording.

## 3. Multi-Language LOA, Inline Hold-Open Scripts, Sentinel-on-Catch, and Rust Corpus Smells

- **Sentinel-on-catch (`catchSentinelReturn` in `ts/no-sentinel-absence-fallback` & `rust/no-silent-result-discard`):** Flags `catch` / `.catch()` branches returning `""` when the happy path returns a non-empty string (`readTrace` collapsing `ENOENT` into `""`), and `fs::read_to_string(...).unwrap_or_default()` in Rust.
- **Multi-language Level-of-Abstraction (`react/no-handrolled-resource-lifecycle-cells` & `rust/no-wrapping-functions`):**
  - `inlineProcessHoldOpenHack`: Flags inline child-process scripts (`*Script` or `-c`/`-e` strings) that print a readiness token and hold the process open with `time.sleep(...)` / `setInterval(...)` instead of stdin-EOF lifetime control, or embed raw Python `socket.socket` + `.bind` + `while True:` loops inside TS/Rust orchestration code.
  - `dualProcessPrimitive`: Flags modules that mix raw `node:child_process` (`spawn`) with an owned child-process lifecycle helper (`spawnOwnedChildProcess`, `runCommand`), and flags blocking `std::thread::sleep` / synchronous `std::process::Command` waits inside `async fn` in Rust.
  - `pollingEventTargetState`: Flags timer-polling (`waitFor`, `pollUntil`) over mutable `let` buffers mutated by `.on("data")` stream listeners.
  - `nestedCleanupPyramid`: Flags 3+ nested `try ... finally` blocks inside a single function in favor of `AsyncDisposableStack` / cleanup stacks.
- **New Rust Corpus Detectors (`crates/antidrift-linter/src/rust/corpus_smells.rs`):**
  - Error-message control flow (`err.to_string().contains(...)` in `if` conditions and `match` guards).
  - Nested $O(N \times M)$ iterator key-equality lookup joins (`.iter().map(|a| ... other.iter().find(|b| b.id == a.id))`).
  - `Result` sum-to-product state erasure (`match res { Ok(v) => S { success: true, error: None, .. }, Err(e) => S { success: false, error: Some(e), .. } }`).
  - Fieldwise `.clone()` struct identity rebuilds (`Foo { a: x.a.clone(), b: x.b.clone(), c: x.c.clone() }`).
